## Design
When I was initially designing the website, the concept was to look like a game console home screen. The user would navigate this home screen and select a "game",
where each "game" was another page about skills or projects, etc. Unfortunately, I couldn't get it to look the way I had envisioned so I decided to simplify the
site to emulate the look of a terminal.
